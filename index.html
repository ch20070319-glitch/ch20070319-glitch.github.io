SELECTED BY ASKER / 07 GAMES个人评分 · 满分 5 分
GAME / 01

杀戮尖塔

5 / 5
Roguelike卡牌
阅读我的感想 +

卡牌肉鸽的祖师爷。铁甲战士、静默猎手、故障机器人三套构筑思路完全不同，一局四十分钟左右，路上每一次「拿这张牌还是跳过」的取舍都会累积成结局，这种密度至今没被超越。缺点是对新手不太友好，前三把大概率被第三层教做人，别急着卸载。

GAME / 02

星之侵略者

4 / 5
Roguelike卡牌
阅读我的感想 +

美术玩法都在线的肉鸽游戏，利用卡牌的效果在矩阵上移动或攻击敌人和你自己。缺点是开局的卡牌选择影响较大，难度较少。同公司同世界观作品《骰之侵略者》也不错。

GAME / 03

幻兽帕鲁

4.5 / 5
休闲生存捉宠建造
阅读我的感想 +

方舟+宝可梦，满足了小时候抓精灵游戏的愿望，花丽娜可爱捏

GAME / 04

泡姆泡姆

4 / 5
解密闯关
阅读我的感想 +

鹰角出品的多人合作游戏，灵感来自消消乐游戏祖玛，三消以及各种道具让解密过程有了别样的乐趣。

GAME / 05

传送门2

5 / 5
解密闯关剧情
阅读我的感想 +

传送门和机关间的联动让这款游戏的解谜过程独具本家的特色，个人关卡的剧情也相当不错，值得游玩的神作。

GAME / 06

花园战争2

3.5 / 5
FPSPVZ
阅读我的感想 +

射击游戏续作，单论游戏本身其实还不错，角色的设计很超前（1代的时间比OW还早，属于是很优秀的玩法和角色设计），但是EA和挂b弥补了这一点，呃呃

GAME / 07

How to fish

4 / 5
射击钓鱼
阅读我的感想 +

枪械手感还不错的射击游戏，新晋练枪软件
